# A/B Test – Website Optimization

## 📌 Project Overview
This project demonstrates an end-to-end A/B testing workflow for website optimization.  
The objective of the project is to evaluate whether a proposed website change can improve user conversion in a data-driven way.

---

## 🎯 Business Objective
The primary goal of this experiment is to improve website conversion by testing whether a design change leads to better user engagement and conversion behavior compared to the existing version.

---

## 🧠 Hypothesis
If the proposed website change improves the user experience, then users exposed to the new version (treatment group) will show a higher conversion rate than users in the control group.

---

## 🧪 Experiment Design
- Defined clear control and treatment groups  
- Ensured consistent tracking of key metrics across both groups  
- Collected experiment data over a predefined time period to ensure comparability  

---

## 📊 Metrics
- **Primary metric:** Conversion rate  
- **Secondary considerations:** User behavior patterns and data consistency  

---

## 🔍 Analysis Approach
- Performed data cleaning and validation to ensure accuracy  
- Compared conversion rates between control and treatment groups  
- Applied statistical testing to evaluate the significance of observed differences  
- Interpreted results with a focus on business impact rather than statistical significance alone  

---

## ✅ Results & Decision
- Evaluated whether the hypothesis was supported by the data  
- Assessed both statistical and practical significance  
- Provided a clear recommendation on whether to implement the change or iterate on the experiment  

---

## 🧠 Key Learnings
- The importance of defining clear business objectives and hypotheses before experimentation  
- Treating non-significant results as valuable learning outcomes  
- Using A/B testing as a structured approach to support data-driven product decisions  

---

## 🛠 Tools Used
- Python (Pandas, NumPy, SciPy)  
- Jupyter Notebook
